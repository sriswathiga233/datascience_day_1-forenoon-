# Social Pulse — Social Media & Brand Analytics

> "What Are People Talking About?"

A complete data science project and interactive web dashboard analysing 161,465 Twitter posts
on climate-related topics (September 2017 – May 2019).

---

## Project Structure

```
DS_Day01_42/
├── app.py                  ← Streamlit dashboard (launch this)
├── requirements.txt
├── README.md
├── data/
│   ├── social_media_brand_analytics.csv   ← original dataset (never modified)
│   └── cleaned_social_media.csv           ← generated by pipeline
├── plots/                  ← all visualizations generated by pipeline
├── models/
│   └── naive_bayes_model.pkl
├── results/

└── src/                    ← analysis pipeline (do not modify)

    ├── topic_analysis.py
    ├── sentiment_analysis.py
    ├── trend_analysis.py

```

---

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the pipeline (only needed if outputs are missing)

```bash
cd src
python main.py
```

### 3. Launch the dashboard

From the `DS_Day01_42/` directory:

```bash
streamlit run app.py
```

The dashboard opens at **http://localhost:8501**

## Notes
